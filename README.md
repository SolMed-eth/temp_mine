# Social Media Platform

A modern, full-stack social media platform inspired by Instagram, designed
to provide a secure, responsive, and real-time environment for sharing
content and connecting with other users.

The platform supports user authentication, profile management, posts,
media uploads, likes, comments, follows, advanced search, real-time
messaging, notifications, AI-powered content moderation, GDPR features,
internationalization, and a secured public API.

The project also includes a dedicated administration panel that provides
platform-wide user management, content moderation, role management,
report handling, and analytics.

## Main Features

- Secure authentication and user management
- OAuth 2.0 and 2FA
- User profiles and social interactions
- Image and video sharing
- Likes, comments, follows and feeds
- Advanced search
- Real-time chat and notifications
- WebSocket-based real-time communication
- AI-powered content moderation
- GDPR data export and account deletion
- Multi-language and RTL support
- Secured public API with API keys and rate limiting
- Dedicated admin dashboard
- Role-based access control
- Platform analytics
- Dockerized development and deployment
